WHOOP AI Health 隐私政策

Privacy Policy for WHOOP AI Health

更新日期：2026年11月6日

1. 应用介绍 / Introduction

WHOOP AI Health 是用于个人健康管理的应用， 帮助用户分析 WHOOP 提供的健康与运动数据， 生成每日健康报告。

WHOOP AI Health is a personal health management application that analyzes WHOOP data and generates daily health reports.

2. 数据收集 / Data Collection

经用户授权，本应用可以读取恢复评分、 心率变异性（HRV）、静息心率、睡眠数据、 生理周期和运动记录。

With user authorization, the application may access recovery scores, HRV, resting heart rate, sleep data, physiological cycles, and workout records.

3. 数据用途 / Data Usage

数据用于生成个人健康报告、分析历史趋势、 评估睡眠和运动恢复情况。

Data is used to generate personal health reports, analyze trends, and provide sleep and recovery insights.

4. 数据存储 / Data Storage

本应用设计为在用户个人电脑上保存健康记录， 使用本地数据库存储数据及历史分析结果。 WHOOP 授权信息也保存在本地。

Health records and authorization information are designed to be stored locally on the user's computer.

5. AI 数据处理 / AI Processing

如果用户启用可选的 OpenAI API 分析功能， 相关健康指标可能发送至 OpenAI 进行分析。 用户可以不启用该功能，使用本地基础报告。

If the optional OpenAI API feature is enabled, relevant health metrics may be sent to OpenAI for analysis. This feature is optional.

6. 数据共享 / Data Sharing

本应用不以出售健康数据为目的。 除用户主动启用的第三方 AI 处理服务外， 不主动向其他第三方共享健康记录。

The application does not sell health data. Third-party AI processing occurs only when the optional feature is enabled.

7. 用户控制 / User Control

用户可以停止使用本应用、删除本地保存的健康数据， 并通过 WHOOP 的授权管理功能撤销访问权限。 撤销授权不一定会自动删除此前保存的数据。

Users may stop using the application, delete locally stored data, and revoke WHOOP access authorization. Revoking access does not necessarily delete existing data.

8. 安全与免责声明 / Security and Disclaimer

应用应在受保护的个人电脑上运行。 健康报告仅供个人健康管理参考， 不能替代专业医疗诊断或治疗。

The application should run on a secured computer. Its reports are informational and are not a substitute for professional medical advice.
